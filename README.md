# Codebase Learning Coach

一个面向 AI 时代的 Codex Skill，帮助新手按阶段理解陌生代码库。

它不是传统 CLI，也不是一次性生成超长项目总结的工具。它的目标更小也更实用：让 AI 像导师一样，每次只给你一张“学习卡片”，告诉你当前阶段应该看哪几个文件、具体怎么看、看完后应该理解什么。

## 为什么做成 Skill

新手看项目时真正困难的地方通常不是“没有信息”，而是：

- 不知道第一步该看哪里
- 问 AI 后得到的总结太长
- 一次性看到太多文件和概念
- 缺少循序渐进的阅读顺序

所以这个项目不再做规则扫描器，而是把“如何带新手读代码库”的方法沉淀成一个 Codex Skill，让 AI 在真实项目中先探索、再分阶段讲解。

## 功能

- 引导 AI 先非侵入式探索项目
- 默认中文输出
- 每次只输出一张学习卡片
- 每张卡片最多推荐 1 到 3 个文件
- 对每个文件说明角色、阅读重点和检查点
- 按阶段理解项目：启动方式、入口文件、页面/接口/模块、业务逻辑、测试和部署
- 避免一上来生成完整架构报告，降低信息过载

## 项目结构

```text
skills/
  codebase-learning-coach/
    SKILL.md            Skill 的核心指令
    agents/
      openai.yaml       Codex UI 展示信息
```

## 安装

把 skill 目录复制到你的 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R skills/codebase-learning-coach ~/.codex/skills/
```

重启或刷新 Codex 后即可使用。

## 使用方式

在一个你想学习的项目里，向 Codex 提问：

```text
使用 $codebase-learning-coach，带我快速了解这个项目，从哪里开始？
```

也可以这样问：

```text
我接手了这个项目，但不知道先看哪里，请一步一步带我读。
```

## 输出示例

```md
## 学习卡片：第 1 步

### 这一轮目标
先弄清楚这个项目是什么，以及它从哪里启动。

### 先建立一个小地图
这一轮只看项目入口信息：README 告诉你作者希望别人怎么使用项目，package.json 告诉你真实的运行脚本和依赖。先不要进入业务代码，先确认“项目怎么跑起来”。

### 先看这些
1. `README.md`
   - 角色：项目对外说明。
   - 重点看：项目介绍、安装步骤、启动命令、示例。
   - 看完后应该能说清楚：这个项目要解决什么问题。

2. `package.json`
   - 角色：Node 项目的运行说明书。
   - 重点看：`scripts`、核心依赖、包管理器线索。
   - 看完后应该能说清楚：开发环境用什么命令启动，项目大概率用了什么框架。

### 你要带着这个问题看
这个项目是前端、后端，还是全栈项目？启动命令是哪一个？

### 读完后的检查点
- 你能说出项目的一句话用途。
- 你能找到本地启动命令。
- 你能判断下一步应该去找入口文件。

### 看完后下一步
下一轮进入程序入口，找到代码真正从哪里开始运行。
```

## 设计原则

- 少量信息优先于完整信息
- 先建立方向感，再解释细节
- 先看真实文件，再给学习建议
- 每一轮只解决一个小问题
- 少推荐文件，但把每个文件讲到可操作
- 让新手知道下一步，而不是被全部内容淹没
